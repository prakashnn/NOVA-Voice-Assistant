# NOVA – Voice-Controlled Python Assistant

NOVA is a Python-based voice-controlled desktop assistant that uses speech recognition and text-to-speech to interact with users and automate common desktop/web actions.

## Features

- Voice-based user interaction
- Speech recognition using SpeechRecognition
- Text-to-speech using pyttsx3
- Wake-word style interaction using "NOVA"
- Open websites using voice commands
- Play songs using a custom music library
- YouTube music integration
- Browser automation using Python's webbrowser module
- Experimental OpenAI API integration

## Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- webbrowser
- OpenAI API
- YouTube
- Git & GitHub
